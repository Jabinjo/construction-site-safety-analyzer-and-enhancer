# Construction Site Safety Analyzer and Enhancer

Computer vision-based construction-site safety monitoring using a trained YOLOv5 model.

## Features
- Live webcam object detection
- Hardhat violation detection
- Safety vest violation detection
- Face mask violation detection
- Arduino serial alerts
- Captured images of detected violations

## Technologies
Python, PyTorch, YOLOv5, OpenCV, NumPy, Arduino and SMTP.
